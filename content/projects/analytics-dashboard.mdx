## The problem

The client's existing dashboard refreshed every 30 seconds and consistently missed spikes.

## What I built

- Realtime ingestion pipeline (Redis Streams → worker → Postgres)
- WebSocket layer with backpressure
- Virtualized tables rendering 100k rows at 60fps

## Result

- p95 latency dropped from 28s → 240ms
- 50k events/sec sustained
